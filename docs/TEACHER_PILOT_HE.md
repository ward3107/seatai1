# פיילוט מורים — SeatAI

מטרת הפיילוט: לוודא שמורה מצליח להכין סידור, לתקן אותו ולשחזר את עבודתו ללא עזרה. זהו נוהל מוצע; הפיילוט טרם בוצע.

## תרחיש קצר לכל מורה

1. לפתוח את האתר במכשיר שמשמש בכיתה ולבחור עברית או ערבית.
2. ליצור כיתה עם שמות בדויים בלבד, או לייבא CSV לדוגמה.
3. להגדיר חדר עם מספיק מקומות וליצור סידור.
4. לשנות שני מקומות ולשמור את הכיתה בשם ברור.
5. להוריד PDF ולבדוק שהשמות והכיוון תקינים בהדפסה.
6. לבחור „גיבוי כל הנתונים” בחלונית הפרויקטים ולשמור את הקובץ.
7. לפתוח פרופיל דפדפן נפרד, לשחזר את הקובץ ולוודא שהכיתה חזרה.
8. לרענן ולוודא שהנתונים נשמרו. אין למחוק את נתוני הדפדפן המקורי לצורך הבדיקה.
9. לאחר טעינה מקוונת מלאה, לבדוק טעינה חוזרת ללא רשת. אינטגרציות חיצוניות דורשות חיבור.
